Test Setup

Topic: Internal Medicine (Topic ID: 1)

Scenario: Topic has 3 assignments but user wants to practice regularly

❌ OLD LOGIC (BROKEN)

// Check if this topic is part of an assignment
const topicCard = document.querySelector(`[data-topic-id="1"]`);
const hasAssignment = topicCard && topicCard.dataset.hasAssignment === 'true';

if (hasAssignment) {
    // PROBLEM: Always finds assignment card first!
    // Result: Source modal never shows for regular practice
    window.location.href = originalHref;
    return false;
}

Result: ❌ Source modal never shows, even for regular practice

✅ NEW LOGIC (FIXED)

// Check if assignments filter is currently active
const topicsContainer = document.querySelector('.topics-container');
const isAssignmentsFilterActive = topicsContainer && 
    topicsContainer.classList.contains('assignments-filter-active');

if (isAssignmentsFilterActive) {
    // Only bypass source modal when in assignments mode
    window.location.href = originalHref;
    return false;
}

Result: ✅ Source modal behavior depends on current filter
