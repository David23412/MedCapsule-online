## 📸 QUESTION IMAGES (SUPER SIMPLE!)

### 3-Step Process:

1. **Rename your images:**
   ```
   cardio_001.jpg
   cardio_002.jpg
   neuro_001.png
   ```

2. **Create Excel with this format:**
   ```
   question_text | image_filename | option_a | option_b | option_c | option_d | correct_answer | explanation | course_id | topic_id
   ```

3. **Import everything:**
   ```bash
   php artisan questions:import questions.xlsx --course=1 --images=/path/to/images
   ```

**That's it! No URLs, no cloud setup, no hassle!**
